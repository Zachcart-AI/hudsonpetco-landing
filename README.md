# Hudson Pet Co. landing page

Static landing page for Hudson Pet Co., 250 Hudson St, New York, NY 10013. The online store is
https://hudsonpetco.zachcart.shop/ and every "shop" link on the page points there.

- `index.html`: the whole page (inline CSS and JS, Google Fonts only). No build step.
- `img/`: photos from Unsplash (free license, no attribution required; credited in the footer).

Run locally: `python3 -m http.server 8000` and open http://localhost:8000.
